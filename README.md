# Interactive System Monitor Dashboard

A frontend-only system monitoring dashboard that simulates real-time CPU, memory, disk, and network usage using vanilla JavaScript.

Ronaldo Olvera Jiménez (c) 2025

## Features
- Real-time metrics simulation
- Minimal dark UI
- Alert thresholds (Normal / Warning / Critical)
- Responsive layout
- Pure frontend (no backend)

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Chart.js
